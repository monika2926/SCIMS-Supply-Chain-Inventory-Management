## 📌 Project Overview

The Supply Chain & Inventory Management System (SCIMS) is a database-driven analytics project designed to manage and analyze supply chain, inventory, warehouse, supplier, purchase order, and shipment operations.

The project combines SQL-based data management with Power BI dashboards to transform operational data into meaningful business insights.

---

## 🎯 Project Objectives

- Design a structured relational database for supply chain operations
- Manage warehouse, supplier, product, inventory, order, and shipment data
- Perform data cleaning and transformation using SQL
- Create reusable SQL procedures, functions, triggers, and views
- Analyze business performance using SQL queries
- Build interactive Power BI dashboards
- Generate actionable insights for business decision-making

---

## 🗄️ Database Design

The SCIMS database contains **20 interconnected tables** covering major supply chain operations.

### Major Areas Covered

- Warehouses
- Stores
- Suppliers
- Categories
- Products
- Employees
- Inventory
- Purchase Orders
- Purchase Order Items
- Shipments
- Shipment Tracking
- Stock Transfers
- Transfer Items
- Store Orders
- Store Order Items
- Damaged Stock
- Inventory Audit
- Supplier Performance
- Warehouse Capacity
- Users

The database uses primary keys, foreign keys, unique constraints, default values, ENUMs, and data validation rules to maintain data integrity.

## 📊 Power BI Dashboards

The SCIMS Power BI report contains 7 interactive dashboards designed to analyze different areas of supply chain and inventory operations.

### Dashboard Pages

1. **Executive Dashboard**
   - Provides a high-level overview of overall business and supply chain performance.

2. **Purchase Order Analysis**
   - Analyzes purchase orders, order status, purchasing activity, and related metrics.

3. **Inventory Analysis**
   - Analyzes stock availability, inventory levels, low-stock situations, and reorder requirements.

4. **Warehouse Analysis**
   - Analyzes warehouse capacity, utilization, inventory, and warehouse performance.

5. **Store Analysis**
   - Analyzes store orders, demand, and store-level performance.

6. **Shipment & Transfer Analysis**
   - Analyzes shipments, stock transfers, and logistics-related activities.

7. **Supplier Insights & Performance**
   - Analyzes supplier performance, orders, delivery trends, and supplier-related metrics.---
